## 为什么搭建博客

记录技术成长，分享学习心得。

## 技术选型

- **框架**: Hexo
- **主题**: NexT
- **托管**: GitHub Pages
- **部署**: GitHub Actions 自动部署

## 开始写作

使用 Markdown 编写文章，简洁高效。支持代码高亮、表格、图片等丰富格式。

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello Blog!");
    }
}
```
